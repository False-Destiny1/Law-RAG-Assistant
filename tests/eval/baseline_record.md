## 关键发现

### 成功的改进
1. **R1 从 50% → 100%**：Query Decomposition + HyDE 组合拳，成功检索到劳动合同法第三十九条、第四十条
2. **M2 持续 100%**：多轮融合持续有效
3. **响应时间基本持平**：合并 2 次 LLM 调用为 1 次，抵消了新增的 Query Decomposition + HyDE 开销

### 待优化
1. **R2 回退 67% → 33%**：查询分解将"老板不给加班费怎么办"拆解后引入噪声，需优化 query_analysis_prompt
2. **回答变长**：1309 → 1529，Query Decomposition 使检索到更多文档，上下文更丰富但回答也更冗长
