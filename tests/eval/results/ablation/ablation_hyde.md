# 消融实验: HyDE 检索增强（口语化查询）

> 2 配置 x 2 cases，单次运行
> 生成时间: 2026-06-02 16:05

## 实验设计

| 配置 | 说明 |
|---|---|
| 有 HyDE | LLM 生成假设法律文档辅助向量检索 |
| 无 HyDE | 直接用原始 query 做向量检索 |

## 结果

| Case | Question | 有 HyDE P | 有 HyDE R | 无 HyDE P | 无 HyDE R |
|---|---|---|---|---|---|
| C1 | 老板不给加班费怎么办 | 0.167 | 0.500 | 0.200 | 0.500 |
| C2 | 被公司辞退了能拿多少赔偿 | 0.500 | 0.500 | 0.000 | 0.000 |
| **avg** | | **0.333** | **0.500** | **0.100** | **0.250** |

## 效果量

| 指标 | 变化 |
|---|---|
| Precision | +233% (+0.233) |
| Recall | **+100% (+0.250)** |

## 分析

- **C1（"老板不给加班费怎么办"）**: 有/无 HyDE recall 相同（0.500），因为原始 query 已经能匹配到相关文档
- **C2（"被公司辞退了能拿多少赔偿"）**: HyDE 效果显著——无 HyDE 时 recall=0（完全检索失败），有 HyDE 时 recall=0.500
- HyDE 的核心价值：将口语化表达（"被公司辞退"）转化为法律术语（"用人单位单方解除劳动合同"），弥合语义鸿沟

## 简历写法

> 通过消融实验证明 HyDE 在口语化法律查询场景下 context_recall 提升 100%（0.250 → 0.500），有效弥合用户口语表达与法律文档正式表述的语义差距
