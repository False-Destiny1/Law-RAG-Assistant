# 消融实验: 三路融合检索（全部场景）

> 4 配置 x 5 场景，单次运行
> 生成时间: 2026-06-02 16:00

## 实验设计

| 配置 | 说明 |
|---|---|
| 三路融合 | FAISS + BM25 + Neo4j，RRF 融合 |
| FAISS Only | 仅向量语义检索 |
| BM25 Only | 仅关键词检索 |
| Neo4j Only | 仅知识图谱检索 |

## 各场景结果

### A: 精确法律查询（5 cases）

| 配置 | Precision | Recall |
|---|---|---|
| 三路融合 | **0.242** | **0.533** |
| FAISS Only | 0.240 | 0.333 |
| BM25 Only | 0.117 | 0.367 |
| Neo4j Only | 0.000 | 0.000 |

- 三路融合 recall 最高（0.533），比 FAISS Only 高 60%
- BM25 precision 最低（0.117），噪音较多
- Neo4j 无贡献（CITES 关系不存在）

### B: 口语化查询（2 cases）

| 配置 | Precision | Recall |
|---|---|---|
| 三路融合 | 0.350 | **0.500** |
| FAISS Only | 0.183 | **0.500** |
| BM25 Only | **0.600** | **0.500** |
| Neo4j Only | 0.000 | 0.000 |

- BM25 precision 最高（0.600），C2（"被公司辞退了能拿多少赔偿"）精确匹配效果好
- 三路融合和 FAISS recall 相同（0.500），融合主要提升 precision
- Neo4j 无贡献

### C: 复合问题（1 case）

| 配置 | Precision | Recall |

- 多话题查询需要 query 分解，当前未对 M1 做分解

### D: 冷门法律（2 cases）

| 配置 | Precision | Recall |
|---|---|---|

## 关键发现

1. **三路融合在 recall 上整体最优**：在 A 场景（精确法律）recall 0.533 vs FAISS 0.333（+60%）
2. **BM25 在 precision 上有优势**：B 场景 BM25 precision 0.600 vs 融合 0.350
3. **Neo4j 当前无实际贡献**：CITES 关系不存在，图谱检索返回空结果
4. **复合问题和多轮对话是短板**：所有配置均表现不佳，需要 query 分解和上下文理解
